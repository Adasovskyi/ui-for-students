UI Elements

1. Radiobutton

Дозволяє користувачеві вибрати лише один варіант із набору опцій.


2. Checkbox

Дозволяє користувачеві вибрати один, кілька або жодного варіанту з набору.


3. Text input

Однорядкове поле для введення текстових даних користувачем.

4. Tabs

Вкладки дозволяють організувати та перемикатися між різними розділами контенту в межах однієї області без перезавантаження сторінки.

Вміст першої вкладки.

Вміст другої вкладки.

5. Button

Інтерактивний елемент, який ініціює виконання певної дії після натискання.

6. Text label

Описує елемент керування (наприклад, поле введення), пояснюючи користувачу, яку саме інформацію слід ввести або обрати.

7. Link

Дозволяє користувачеві переходити на іншу веб-сторінку, файл або певну частину поточної сторінки.

Гіперпосилання (Link)

8. Tooltip

Надає додаткову контекстну інформацію або пояснення, коли користувач наводить курсор миші на певний елемент.

Наведіть курсор на це слово:
Підказка Це додаткова інформація, яка з'являється при наведенні

9. Dropdown list

Дозволяє користувачеві вибрати одне значення з прихованого списку, що розгортається після натискання.

10. Data grid

Відображає структуровані дані у форматі таблиці. Використовується для організації та перегляду великих обсягів інформації.
